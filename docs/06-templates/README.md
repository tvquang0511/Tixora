# 06 — BIỂU MẪU CHUẨN (STANDARD TEMPLATES)

Thư mục này cung cấp các template mẫu chuẩn hóa dùng khi tạo Issue, báo cáo lỗi hoặc tạo Pull Request trên GitHub/GitLab.

## 📑 Danh Sách Biểu Mẫu

| Biểu mẫu | Mục đích sử dụng |
| :--- | :--- |
| **[pr-template.md](./pr-template.md)** | Mẫu mô tả khi tạo Pull Request: Tóm tắt thay đổi, kiểm tra Quality Gates, checklist tự review. |
| **[bug-report-template.md](./bug-report-template.md)** | Mẫu báo cáo lỗi: Các bước tái hiện, hành vi thực tế vs mong đợi, ảnh chụp màn hình/log. |
| **[task-template.md](./task-template.md)** | Mẫu mô tả công việc (Task/Feature): Phạm vi (Scope), Checklist thực hiện và Tiêu chí nghiệm thu. |
