# 06 — BIỂU MẪU CHUẨN (STANDARD TEMPLATES)

Thư mục này cung cấp các template mẫu chuẩn hóa dùng khi tạo Issue, báo cáo lỗi hoặc tạo Pull Request trên GitHub/GitLab.

## 📑 Danh Sách Biểu Mẫu

| Biểu mẫu | Mục đích sử dụng |
| :--- | :--- |
| **[PR_TEMPLATE.md](./PR_TEMPLATE.md)** | Mẫu mô tả khi tạo Pull Request: Tóm tắt thay đổi, kiểm tra Quality Gates, checklist tự review. |
| **[BUG_REPORT_TEMPLATE.md](./BUG_REPORT_TEMPLATE.md)** | Mẫu báo cáo lỗi: Các bước tái hiện, hành vi thực tế vs mong đợi, ảnh chụp màn hình/log. |
| **[TASK_TEMPLATE.md](./TASK_TEMPLATE.md)** | Mẫu mô tả công việc (Task/Feature): Phạm vi (Scope), Checklist thực hiện và Tiêu chí nghiệm thu. |
